# Free-tail Transect

An interactive map of where and when the White-striped Free-tailed Bat
(*Austronomus australis*) is heard at dusk across Australian Acoustic
Observatory sites, by season.

**Map:** https://willcornwell.org/freetail-transect/

Presence is the share of sampled dusks (first 1.5 h after sunset) on which a
signal-processing detector found the bat and an A2O-trained Perch classifier
confirmed it, at 25 A2O sites from 17 to 42 deg S, recorded 2019-2026.

`index.html` is a single self-contained page: the data are embedded, and D3 and
fonts load from public CDNs. It is generated by the analysis code, so edit there
rather than here.
